# Gem Collector 💎

A 2D arcade-style gem collection game built with **Godot 4**. Created as a foundational hands-on project to learn engine architecture, GDScript physics, signal handling, and UI layout.

## 🕹️ Features
- **Responsive Movement:** Custom 8-directional movement mapped to Arrow keys and WASD.
- **Area Trigger Signals:** Dynamic touch-to-collect collision detection.
- **CanvasLayer HUD:** Decoupled UI tracking collected gems in real time.
- **Win Condition State:** Group-based node checking that triggers a win screen upon clearing the level.

## 🛠️ Built With
- **Engine:** Godot 4
- **Language:** GDScript
- **Version Control:** Git & GitHub

## 🚀 How to Run
1. Clone this repository: `git clone https://github.com/YOUR_USERNAME/gem-collector.git`
2. Open **Godot 4 Engine**.
3. Click **Import** and select the `project.godot` file inside the repository directory.
4. Launch the project by pressing **F5**.
